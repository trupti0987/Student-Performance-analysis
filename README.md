# Student-Performance-analysis
A beginner-friendly data science project to analyze and predict student performance using Python and machine learning.
# Student Performance Analysis and Prediction 📊

## Objectives

* Clean and analyze student data
* Perform EDA and data visualization
* Find relationships between student factors and grades
* Build Machine Learning models
* Predict final student grades

## Dataset

**UCI Student Performance Dataset**

Target variable: **G3 – Final Grade**

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Workflow

**Data Collection → Cleaning → EDA → Visualization → Correlation → Feature Selection → ML → Evaluation → Prediction**

## Models Used

* Linear Regression
* Random Forest Regression

## Evaluation Metrics

* MAE
* MSE
* RMSE
* R² Score

## Prediction

The project predicts a student's final grade and classifies performance as:
**Excellent, Good, Average, or Needs Improvement.**
